# Plan: Phase 2 - Smoke Test (Revised)

## Goal
Verify the bridge MCP server connects to live OpenCode instances and the reviewer terminal correctly refuses write operations.

## Key Learnings from Exploration
1. **OpenCode servers generate random passwords** on each startup - must capture and pass to bridge
2. **`--config` flag doesn't work** with `opencode mcp list` - must use `OPENCODE_CONFIG` env var
3. **Previous test sessions pollute discovery** - need clean state or handle multiple sessions
4. **Bridge uses `OPENCODE_DEV_PASS` / `OPENCODE_REV_PASS`** env vars for auth

## Current State
- ✅ Bridge MCP server logic tested (tools, findings storage, resolve/skip/mark-fixed)
- ✅ package.json updated with `setup`, `start:all`, `attach:dev`, `attach:review`, `concurrently` devDependency
- ✅ npm dependencies installed (including concurrently)
- ❌ Live OpenCode connection NOT verified (password/auth flow broken)
- ❌ MCP tools visibility NOT verified
- ❌ Reviewer read-only enforcement NOT verified

## Assumptions
1. OpenCode CLI v2.1.3 is installed and authenticated
2. Git repo exists with ≥1 commit and working `npm test`
3. gitleaks/semgrep optional for now (can skip in GATE_CMDS)
4. Bridge files (`bridge.mjs`, configs) already copied to project root

## Phase 2 Tasks

### 2.1 Clean State & Start Servers with Password Capture
- **Action**: Kill any existing processes on 4096/4097/5000
- **Action**: Start dev server, capture password from logs
- **Action**: Start reviewer server, capture password from logs
- **Verify**: Both servers respond to `/api/session` with captured passwords

### 2.2 Start Bridge with Captured Passwords
- **Command**: `OPENCODE_DEV_PASS=<dev_pass> OPENCODE_REV_PASS=<rev_pass> npm run bridge`
- **Verify**: Bridge logs show "MCP server listening" and discovers sessions (may show "multiple sessions found" warning - acceptable)

### 2.3 Verify MCP Tools Visible
- **Command**: `OPENCODE_CONFIG=./opencode.developer.json opencode mcp list`
- **Command**: `OPENCODE_CONFIG=./opencode.reviewer.json opencode mcp list`
- **Verify**: Both show `bridge_submit_finding`, `bridge_submit_verdict`, `bridge_mark_fixed`, `bridge_record_decision`, `bridge_get_state`

### 2.4 Verify Reviewer Read-Only Enforcement
- **Action**: In Developer terminal (attach via `npm run attach:dev`), ask: "Ask the reviewer to edit package.json"
- **Verify**: Reviewer responds with refusal ("I cannot edit files" or similar)
- **Check**: No file modifications occur

### 2.5 Verify Bridge Logs
- **Check**: Bridge terminal shows startup messages (MCP server listening on :5000)
- **Check**: Session discovery works (even with warnings)
- **Check**: No connection errors between bridge and OpenCode instances

## Success Criteria
- [ ] `npm run setup` completes without errors
- [ ] Dev server starts, password captured, session created via API
- [ ] Reviewer server starts, password captured, session created via API
- [ ] Bridge starts with captured passwords, discovers sessions
- [ ] `opencode mcp list` shows bridge tools in BOTH configs (using OPENCODE_CONFIG env var)
- [ ] Reviewer refuses write/edit request
- [ ] Bridge logs show healthy MCP connections

## Failure Modes & Mitigation
| Failure | Mitigation |
|---------|------------|
| `opencode` command not found | Install OpenCode CLI first (Phase 1) |
| Port conflicts (4096/4097/5000) | Kill existing processes: `lsof -ti :4096,:4097,:5000 \| xargs kill` |
| MCP tools not visible | Check `opencode.developer.json` / `opencode.reviewer.json` have correct `mcpServers` config |
| Reviewer allows edits | Verify `opencode.reviewer.json` has `permissions: { edit: false, write: false, patch: false, bash: false }` |
| Bridge crashes | Check bridge.mjs logs; verify `@opencode-ai/sdk` compatibility |
| Password auth fails | Ensure OPENCODE_DEV_PASS/OPENCODE_REV_PASS match server passwords exactly |
| Multiple sessions found | Warning is acceptable; bridge picks first. Clean up `.review/` if needed |

## Validation Commands (run in order)
```bash
# Clean up
lsof -ti :4096,:4097,:5000 | xargs kill 2>/dev/null; echo "cleaned"

# 2.1 Start dev server, capture password
OPENCODE_CONFIG=./opencode.developer.json opencode serve --port 4096 --hostname 127.0.0.1 > /tmp/dev.log 2>&1 &
DEV_PID=$!
sleep 3
DEV_PASS=$(grep "server password" /tmp/dev.log | awk '{print $3}')
echo "Dev password: $DEV_PASS"
curl -X POST http://127.0.0.1:4096/api/session -H "Content-Type: application/json" -u "opencode:$DEV_PASS" -d '{}'

# 2.1 Start reviewer server, capture password
OPENCODE_CONFIG=./opencode.reviewer.json opencode serve --port 4097 --hostname 127.0.0.1 > /tmp/rev.log 2>&1 &
REV_PID=$!
sleep 3
REV_PASS=$(grep "server password" /tmp/rev.log | awk '{print $3}')
echo "Rev password: $REV_PASS"
curl -X POST http://127.0.0.1:4097/api/session -H "Content-Type: application/json" -u "opencode:$REV_PASS" -d '{}'

# 2.2 Start bridge with captured passwords
OPENCODE_DEV_PASS=$DEV_PASS OPENCODE_REV_PASS=$REV_PASS npm run bridge
# (run in separate terminal or background)

# 2.3 Verify MCP tools (in another terminal)
OPENCODE_CONFIG=./opencode.developer.json opencode mcp list
OPENCODE_CONFIG=./opencode.reviewer.json opencode mcp list

# 2.4 Attach to developer and test reviewer refusal
npm run attach:dev
# In TUI: "Ask the reviewer to edit package.json"
```
